# EasyBlue Studio

Modern Windows 11 controller and visual interface for EasyBlue Bluetooth KVM devices.

## Features
- Direct native Windows HID driverless integration
- Modern Windows 11 Fluent dark UI
- Per-Monitor DPI v2 dynamic scaling
- Zero-latency multi-monitor mouse boundary traversal
- Smart UTF-16 clipboard streaming for Korean and foreign text
- Mobile control hotkey deck

## Building
Run ./build.ps1 from PowerShell on Windows 10/11 with .NET Framework 4.8.
